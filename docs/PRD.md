# 톡맨스 (Talkmance) — 제품 요구사항 정의서 (PRD)

> 버전: v1.5.0 · 작성일: 2026-08-13 · 플랫폼: macOS + Server(Go)

---

## 1. 제품 개요

### 1.1 한 줄 소개
**언제든 수다 떨 수 있는 다정한 대화 상대, 톡맨스(Talkmance)** — 사용자의 이상형을 AI 캐릭터로 만들어 실시간으로 이어지는 로맨스 대화를 즐기는 AI 연애 채팅 앱.

### 1.2 제품 슬로건
- 내 이야기(일상 생활 이야기도)를 온전히 들어줄 다정한 대화 상대
- 대화로 만드는 나만의 로맨스
- 이상형과의 설레는 톡, 오늘부터 1일

### 1.3 타겟 사용자
- 연애/로맨스 감성을 원하는 성인 (만 19세 이상)
- AI 캐릭터와 실제 연인처럼 대화하고 싶은 사용자
- 일상 이야기를 들어주는 상대가 필요한 사용자

### 1.4 경쟁 서비스 참고
| 서비스 | 벤치마크 포인트 |
|---|---|
| 제타 (zeta) | 카테고리 → 캐릭터 선택 UX, 카톡형 대화 UI, 캐릭터 설정(성격/말투/이상형) |
| 러비더비 | 관계 단계(썸→연인→기념일), 호감도, 첫 상황 추천 |
| 멜팅 | 호감도 게이지, 감정 기억 엔진 |
| 너티 | 자연스러운 카톡 말투, 선톡 |
| Kindroid / Nomi | 3계층 기억 아키텍처 (단기/중기/장기) — 장기 기억 RAG 핵심 참고 |
| HoneyChat | 수위 단계 조절, 벡터 DB 기억 |

### 1.5 차별화 포인트
1. **진짜 장기 기억 (pgvector RAG)**: 1,000개가 넘는 대화도 "지난주에 초밥 먹고 싶다고 했잖아" 수준으로 기억
2. **모델 즉시 전환 + 기억 연속성**: 대화 중 모델을 바꿔도 페르소나와 기억이 그대로 유지
3. **최저 비용 구조**: OpenRouter Free 모델 중심 + 사용자 BYOK → 서비스 자체는 무료
4. **수위 제한 없음**: 스토어 미배포 성인 전용 앱 (19금 자유)

## 2. 핵심 기능 요구사항

### 2.1 캐릭터 (대화 상대) — P0
- [ ] 카테고리 기반 캐릭터 선택 (예: 무심한 듯 다정한 소꿉친구, 댕댕이 같은 연하 남/여친, 차분하고 어른스러운 연상)
- [ ] 캐릭터 생성: 이름/성격/말투/관계/이상형/첫 대화 인트로 설정
- [ ] 캐릭터 프로필 이미지: 기본 아바타 세트(무료) + 사용자 업로드 + AI 생성(v1.1)
- [ ] 캐릭터별 대화 히스토리 유지, 초기화 가능

### 2.2 대화 (채팅) — P0
- [ ] 카카오톡/라인 스타일의 대화 UI (말풍선, 읽음 표시, 타임스탬프)
- [ ] 대화 시작 시 **모델 선택 + 대화 규칙(프롬프트) 선택**
- [ ] 대화 중 모델 즉시 전환 (기존 대화/기억 유지)
- [ ] 할당량 표시: 모델 선택 화면 + 대화창 (남은 대화 수/크레딧 잔액)
- [ ] 대화 기록 자동 저장

### 2.3 대화 규칙 (시스템 프롬프트 관리) — P0
- [ ] 여러 대화 규칙 생성/저장/수정/삭제
- [ ] 규칙 예시: [시스템 역할 설정] AI 캐릭터 페르소나 + [대화 규칙] 반말, 짧은 문장, ㅋㅋㅋ/이모지/괄호 묘사 사용
- [ ] 캐릭터 설정 데이터를 규칙에 자동 삽입
- [ ] 모델이 바뀌어도 규칙은 유지 적용

### 2.4 모델 관리 — P0
- [ ] OpenRouter Free 모델 실시간 목록 연동 (`GET /api/v1/models`)
- [ ] 커스텀 모델 수동 추가: 이름/모델 ID/Base URL/API 키/무료·유료 구분/설명/할당량 표시 여부
- [ ] 모델별 설명 (한국어 성능, 감정선, 상황극 몰입도 등)
- [ ] API 키 없으면 해당 모델 선택 불가 처리

### 2.5 장기 기억 — P0
- [ ] 3계층 기억: 단기(최근 20~30턴 컨텍스트) + 중기(주기적 대화 요약) + 장기(pgvector RAG 검색)
- [ ] 메모리 카드: AI가 포인트(여행, 선물, 생일 등) 자동 추출 저장, 사용자 편집/고정
- [ ] 기억 프롬프트: "지난주에 그거 기억해?" 형식으로 이전 기억 회상

### 2.6 성인 콘텐츠 — P0
- [ ] 수위 제한 없음 (19금 대화 허용) — 스토어 미배포 정책
- [ ] 미성년자 가입 방지 동의 (19세 이상 확인)
- [ ] AI 생성물 워터마크 문구 (선택)

### 2.7 설정 — P0
- [ ] OpenRouter API 키 설정 (BYOK: 입력 시 사용자 키 우선 사용)
- [ ] 서버 공용 키 모드 (키 미입력 시 서버 키 사용)
- [ ] 직접 API 추가 (Gemini/ChatGPT/Claude 등) — v1.1

### 2.8 계정/데이터 — P0
- [ ] 간단한 사용자 로그인 (익명 ID 또는 이메일) — v1.0은 익명 기기 ID 기반
- [ ] 대화/캐릭터/메모리 서버 동기화

## 3. 비기능 요구사항

| 항목 | 요구사항 |
|---|---|
| 성능 | 대화 스트리밍 첫 토큰 ≤ 3초 (Free 모델), 콜드 스타트 허용(무료 티어) |
| 메모리 | macOS ≤ 250MB, 서버 ≤ 256MB (Render 무료 티어) |
| 가격 | 서비스 자체 $0 유지 (Render/Neon 무료 티어 + BYOK) |
| 보안 | API 키는 서버 .env 또는 사용자 키체인/Keystore에만 저장, 로그 금지 |
| 배포 | GitHub Releases DMG(macOS), 스토어 미배포 |
| 언어 | UI/문서/에러 메시지 한국어 |

## 4. 사용자 시나리오 (핵심 플로우)

### 시나리오 1: 캐릭터 선택 → 대화 시작
```
1. 앱 실행 → 캐릭터 카테고리 화면
2. 캐릭터 선택 (또는 직접 생성)
3. 대화 시작 설정: 모델 선택(Free 모델 목록) + 대화 규칙 선택
4. 카톡형 대화 시작 (첫 인트로 메시지)
```

### 시나리오 2: 대화 중 모델 전환
```
1. 대화창 상단 모델 표시 영역 탭
2. 모델 목록 + 할당량 잔여 표시 확인
3. 다른 모델 전환 → 기존 히스토리/기억 그대로 이어서 대화
```

### 시나리오 3: 장기 기억 회상
```
1. 며칠 뒤 다시 대화 시작
2. "지난주에 같이 여행 가고 싶다고 했잖아" 라고 캐릭터가 언급
3. (배경: pgvector RAG가 관련 대화 벡터 검색 → 시스템 프롬프트에 삽입)
```

### 시나리오 4: 모델 직접 추가
```
1. 설정 → 모델 관리 → 새 모델 추가
2. 이름/모델 ID/Base URL/API 키 입력
3. Free/유료 구분 + 설명 입력 → 대화 모델 목록에 활성화
```

## 5. 성인 콘텐츠 정책 (v1.0 확정)

- **스토어 미배포** (GitHub Releases/dmoz 직접 배포) → 스토어 성인 정책 제약 없음
- 수위 제한 없음, 그러나 아래 최소 장치 유지:
  - 만 19세 미만 이용 금지 확인 문구
  - 미성년자 캐릭터 설정 금지 문구 (캐릭터 생성 시 연령 입력, 19세 미만 차단)
  - 폭력/혐오/불법 콘텐츠는 모델 정책에 따름 (모델이 거부하면 그대로 전달)
