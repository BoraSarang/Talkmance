Features

왜 톡맨스인가요?

단순한 챗봇이 아닙니다. 당신과 캐릭터 사이의 관계가 쌓이는, 살아 있는 대화.

진짜 장기 기억 (RAG)

대화 중 알게 된 사실을 자동 저장하고, 질문에 맞는 기억을 찾아 녹입니다. "지난주에 초밥 먹고 싶다고 했잖아" — 그런 수준의 대화.

모델 즉시 전환

대화 중 모델을 바꿔도 페르소나와 기억이 그대로 유지됩니다. OpenRouter Free 모델 중심의 최저 비용 구조.

대화 규칙 관리

캐릭터별 말투·프롬프트를 저장하고 관리합니다. 모델이 바뀌어도 규칙은 유지됩니다.

수위 제한 없음

성인 전용. 성인 캐릭터는 자유로운 대화가 가능하고, 비성인 캐릭터는 자동으로 건전한 대화를 유지합니다.

캐릭터 상세 관리

페르소나(성격/취미/말투/이상형), 메모리 카드 고정·편집·삭제, 대화방 목록까지 — 캐릭터를 더 깊이 알아가세요.

무료 할당량 + BYOK

매일 50회 무료 대화 + 사용자 API 키(BYOK) 지원. 서비스 자체는 무료입니다.
